# 2026-04-22 Gangnam Voice Mode

## 배경

기본 slap 반응을 macOS 내장 효과음 대신 한국어 음성 반응으로 바꾸고 싶다는 요청이 있었습니다.

## 문제 또는 목표

- 일반 slap 에서는 `오빠 강남스타일` 이 나오게 한다.
- 오래/연속 slap 에서는 `예~~~` 가 나오게 한다.
- 기존 `--sound` override 기능은 유지한다.

## 변경 내용

- 기본 오디오 모드를 `gangnam` 음성 모드로 변경했습니다.
- 기본 모드에서 macOS `say` 기반 한국어 음성 재생을 사용합니다.
- 짧은 시간 안에 연속 3회 이상 slap 되면 긴 반응 문구를 재생합니다.
- `--sound` 로 내장 사운드나 사용자 파일을 지정하면 기존처럼 단일 사운드 재생으로 동작합니다.

## 설계 이유

- 별도 음원 파일 없이 바로 동작하게 하려면 macOS `say` 가 가장 단순합니다.
- 현재 감지 구조에는 "길게 누르기" 개념이 없어서, 가장 가까운 사용자 의도인 "짧은 시간 안의 연속 slap" 으로 해석했습니다.
